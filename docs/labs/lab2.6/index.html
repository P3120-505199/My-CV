    Цель работы

    Освоить методы очистки и трансформации данных с использованием библиотеки pandas на примере реальных данных из соревнования Kaggle «Titanic: Machine Learning from Disaster». Научиться выявлять и корректно обрабатывать пропуски, преобразовывать типы данных, создавать новые признаки, бороться с выбросами и проводить агрегирующий анализ.

    Теоретические сведения

    Предобработка данных — это комплекс мер по подготовке «сырых» данных к анализу и машинному обучению.
    Очистка данных включает устранение ошибок, дубликатов, пропусков.
    Трансформация данных — преобразование признаков (кодирование категорий, создание новых переменных, нормализация).
    Pandas — основная библиотека Python для работы с табличными данными, предоставляющая структуры DataFrame и Series, а также мощные средства группировки, фильтрации и агрегации.

    Обработка пропусков

    1. Столбцы с пропусками: Age, Cabin, Embarked.
    2. Пропуски в возрасте (Age)
    3. Среднее = 29.70, медиана = 28.0.
    4. Принято решение заполнить пропуски медианой (устойчива к выбросам).
    5. Создан новый признак Age_group (категории: child, teenager, young adult, adult, middle aged, senior) на основе заполненного возраста.

    ```python filled_df['Age'] = df['Age'].fillna(df['Age'].median()) bins = [0, 12, 18, 30, 45, 60, 130] labels = ['child', 'teenager', 'young adult', 'adult', 'middle aged', 'senior'] filled_df['Age_group'] = pd.cut(filled_df['Age'], bins=bins, labels=labels, right=False) Пропуски в порту посадки (Embarked)

    Мода = 'S' (встречается чаще всего).

    Два пропущенных значения заменены на 'S'.

    Пропуски в каюте (Cabin)

    Извлечена первая буква (палуба) в новый признак Deck.

    Пропуски в Deck заполнены значением 'Unknown'.

    python filled_df['Deck'] = df['Cabin'].str[0] filled_df['Deck'].fillna('Unknown', inplace=True) Результат обработки пропусков: все пропуски в исходных столбцах устранены, созданы новые значимые признаки.

    Трансформация данных Преобразование Pclass в категориальный строковый тип Маппинг: {1: 'F', 2: 'S', 3: 'T'}. Новый признак Pclass_cat.

    Извлечение титула (Title) из имени С помощью регулярного выражения извлечена часть между запятой и точкой. Редкие титулы (Dr, Rev, Col, Major и др.) объединены в категорию 'Rare'. Итоговые категории: Mr, Miss, Mrs, Master, Rare.

    Кодирование пола Sex_num = 1 для male, 0 для female.

    Размер семьи FamilySize = SibSp + Parch + 1 (включая самого пассажира).

    Одиночество IsAlone = 1, если FamilySize == 1, иначе 0.

    Все преобразования выполнены в копии DataFrame (filled_df).

    Обработка выбросов Признак Fare Построен boxplot – видны многочисленные выбросы выше верхней границы. IQR-метод:

    Q1 = 7.91, Q3 = 31.0, IQR = 23.09

    Нижняя граница = -26.72, верхняя = 65.63

    Количество выбросов = 116.

    Для смягчения влияния выбросов применена винсоризация (winsorization) – значения выше 95-го перцентиля заменены на 95-й перцентиль (p95 ≈ 65.63). Создан новый признак Fare_winsorized. Сравнение boxplot до и после показывает компактное распределение без экстремальных значений.

    Признак Age Выбросы не обрабатывались, так как распределение близко к нормальному и отсутствуют аномалии, подтверждённые гистограммой.
