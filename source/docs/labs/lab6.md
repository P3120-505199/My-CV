## Цель работы
Сравнить скорость выполнения рекурсивного и нерекурсивного варианта построения бинарного дерева (реализованные в лабораторных работах 3 и 5 соответственно), а также познакомиться с библиотеками timeit и matplotlib
## Код программы
```python
import timeit
import matplotlib.pyplot as plt
from iterative import gen_bin_tree_iterative
from recursive import gen_bin_tree_recursive

def benchmark(func, heights, roots, number=100, repeat=3):
    """Возвращает среднее время выполнения func на наборе данных."""
    total_time = 0
    count = 0
    for height in heights:
        for root in roots:
            try:
                times = timeit.repeat(
                    lambda: func(height, root),
                    number=number,
                    repeat=repeat
                )
                """Среднее время за один вызов"""
                total_time += min(times) / number
                count += 1
            except Exception as e:
                print(f"Ошибка при height={height}, root={root}: {e}")
                continue

    return total_time / count if count > 0 else 0


def main():
    """Основная функция для сравнения производительности."""
    test_data = list(
        range(1, 8))

    res_recursive = []
    res_iterative = []

    for n in test_data:
        """Тестируем с фиксированным корнем (например, 1)"""
        recursive_time = benchmark(gen_bin_tree_recursive, [
                                   n], [1], number=10, repeat=3)
        iterative_time = benchmark(gen_bin_tree_iterative, [
                                   n], [1], number=10, repeat=3)

        res_recursive.append(recursive_time)
        res_iterative.append(iterative_time)

        print(
            f"Высота={n}: Рекурсивная={recursive_time:.6f}с, Итеративная={iterative_time:.6f}с")

    """Визуализация"""
    plt.figure(figsize=(10, 6))
    plt.plot(test_data, res_recursive, 'o-',
             label="Рекурсивный метод", linewidth=2)
    plt.plot(test_data, res_iterative, 's-',
             label="Итеративный метод", linewidth=2)
    plt.xlabel("Высота дерева (n)")
    plt.ylabel("Среднее время выполнения (сек)")
    plt.title(
        "Сравнение производительности рекурсивного и итеративного методов генерации бинарного дерева")
    plt.grid(True, alpha=0.3)
    plt.legend()
    plt.tight_layout()
    plt.show()


if __name__ == "__main__":
    main()
```
