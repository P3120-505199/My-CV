## Визуализация данных
В результате работы были созданы следующие графики, сохранённые в директории plots/:

1. Гистограмма распределения оценок по математике
Файл: plots/histogram.png

Гистограмма показывает частотное распределение оценок студентов по математике, позволяя оценить общую успеваемость группы и выявить наиболее характерные оценки.

2. Тепловая карта корреляции предметов
Файл: plots/heatmap.png

Тепловая карта отображает корреляцию между оценками по трём предметам (математика, физика, информатика). Высокие значения корреляции (близкие к 1) указывают на сильную взаимосвязь между успеваемостью по разным предметам.

3. График зависимости "студент - оценка по математике"
Файл: plots/students_marks.png

Точечный график показывает распределение оценок каждого студента по математике, что позволяет наглядно представить успеваемость отдельных учащихся.
