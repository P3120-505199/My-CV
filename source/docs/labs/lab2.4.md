## Реализация классификации

### Загрузка и предобработка данных

- Данные загружены с помощью `pandas.read_csv()`.  
- Проведена проверка на пропуски: метод `info()` показал наличие пропусков в столбцах `MonthlyIncome` и `NumberOfDependents`.  
- Пропуски заполнены **средними значениями** из обучающей выборки (чтобы избежать подглядывания в тестовые данные).  
- Целевая переменная `SeriousDlqin2yrs` отделена от признаков.

### Обучение базовых моделей

#### Логистическая регрессия   
```python
from sklearn.linear_model import LogisticRegression

log_reg.fit(training_points, training_values)
```
#### Случайный лес
```python
from sklearn.ensemble import RandomForestClassifier

```

## Самостоятельная работа
### Другие модели
SVM (линейный) – обучение заняло около 15 минут, AUC = 0.74. С RBF‑ядром не удалось обучить из‑за большого объёма данных (MemoryError).

kNN (k=5) – после нормализации признаков (StandardScaler) предсказания на тесте заняли ~3 минуты, AUC = 0.71. kNN плохо работает с несбалансированными классами.

Градиентный бустинг

```python
from sklearn.ensemble import GradientBoostingClassifier
gb = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1)
AUC = 0.87, что лучше случайного леса. Однако обучение дольше.
```

Вывод: для данной задачи лучший результат (AUC=0.87) показал градиентный бустинг. Случайный лес – хороший компромисс между скоростью и качеством.

Современные алгоритмы классификации
Анализ публикаций (Google Scholar, arXiv) и лидерских решений на Kaggle (соревнование «Give Me Some Credit») показывает, что в настоящее время для кредитного скоринга чаще всего используют:

XGBoost – оптимизированная реализация градиентного бустинга с регуляризацией. Очень популярен, даёт AUC до 0.89–0.91.

LightGBM – ещё быстрее, поддерживает категориальные признаки, эффективно работает с большими данными.

CatBoost – хорошо справляется с категориальными признаками «из коробки», реже переобучается.

Ансамбли (стэкинг) – комбинация нескольких моделей (например, XGBoost + логистическая регрессия) даёт дополнительный прирост точности.

Пример из Kaggle: топ-3 решения использовали XGBoost с тщательной предобработкой (заполнение пропусков медианой, удаление выбросов, создание новых признаков типа «отношение долга к доходу» и «количество просрочек за последние 90 дней»).

Загружаем модель и скейлер при старте.

Определяем Pydantic‑схему для входных данных (10 признаков).

Эндпоинт /predict

```python
@app.post("/predict")
def predict(features: InputFeatures):
    X = np.array([features.dict().values()])
    X_scaled = scaler.transform(X)   # если нужно
    prob = model.predict_proba(X_scaled)[0, 1]
    return {"default_probability": prob, "default_prediction": int(prob > 0.5)}
```
